# Code of Conduct

## Our Pledge

We as contributors, maintainers, and community members pledge to make participation in the Finder project a welcoming, respectful, and harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

We are committed to fostering an open, collaborative, and inclusive community where everyone can learn, contribute, and grow together.

---

## Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and professional.
- Providing constructive feedback.
- Being open to different ideas and perspectives.
- Helping new contributors learn the project.
- Accepting feedback gracefully.
- Focusing on what is best for the project.
- Showing empathy toward other community members.

Examples of unacceptable behavior include:

- Harassment or discrimination of any kind.
- Personal attacks, insults, or abusive language.
- Trolling or intentionally disruptive behavior.
- Publishing private information without permission.
- Spam or irrelevant promotional content.
- Any behavior that negatively impacts the community.

---

## Collaboration Guidelines

To keep Finder maintainable and enjoyable for everyone:

- Discuss significant changes before implementing them.
- Follow the project's coding standards.
- Write clear and meaningful commit messages.
- Keep Pull Requests focused on a single purpose.
- Respect code reviews and reviewer feedback.
- Do not merge your own Pull Request unless explicitly permitted.

---

## Our Responsibilities

Project maintainers are responsible for:

- Reviewing contributions fairly.
- Providing constructive feedback.
- Enforcing this Code of Conduct consistently.
- Taking appropriate action against unacceptable behavior.

Maintainers may edit, reject, or remove contributions that violate this Code of Conduct.

---

## Reporting Issues

If you experience or witness unacceptable behavior, please report it privately to the maintainers.

GitHub Issues should **not** be used for reporting Code of Conduct violations.

Contact:

- GitHub Discussions (general questions)
- GitHub Security/Private contact (for sensitive matters)
- Discord Server Moderators

All reports will be reviewed confidentially whenever possible.

---

## Enforcement

Community leaders will investigate reported incidents and determine appropriate responses.

Possible actions include:

1. Warning
2. Temporary restriction
3. Removal from the community
4. Permanent ban from the project

The severity of the action depends on the nature and frequency of the violation.
